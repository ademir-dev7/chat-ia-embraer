# ✈️ Chat IA Embraer

Assistente virtual técnico de aviação desenvolvido com Python e IA generativa.

## 🤖 Sobre o Projeto

Chatbot especializado em aviação, capaz de responder perguntas técnicas
sobre aeronaves, operações e conceitos aeronáuticos, utilizando o modelo
LLaMA 3.3 70B via API da Groq.

## 🚀 Tecnologias

- Python 3.x
- [Groq API](https://console.groq.com)
- LLaMA 3.3 70B Versatile

## ⚙️ Como Rodar

1. Clone o repositório:
   git clone https://github.com/ademir-dev7/chat-ia-embraer.git

2. Instale as dependências:
   pip install -r requirements.txt

3. Crie o arquivo .env com sua chave:
   GROQ_API_KEY=sua_chave_aqui

4. Execute:
   python Chat-bot.py

## 📌 Observação

O assistente responde apenas perguntas relacionadas à aviação.
